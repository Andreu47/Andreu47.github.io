Resum

De què va tractar el workshop

Vam fer una introducció pràctica a la programació amb tres exemples senzills en Kotlin. Abans de començar amb el codi, vam simular el funcionament d'un plotter per entendre que un ordinador executa exactament les instruccions que rep.

Aprenentatges

Què hem après

  • Les instruccions d'un programa han de ser precises i seguir un ordre.
  • print i println mostren informació, mentre que readln permet introduir dades.
  • Les variables guarden valors de tipus String, Int, Float o Boolean.
  • Els operadors permeten fer càlculs, concatenar text i treballar amb condicions.
  • La instrucció if executa un bloc només quan es compleix una condició.

Activitats

Exercicis i exemples

1. Simulació d'un plotter

Una persona feia de programador i una altra de plotter. Només es podien utilitzar les ordres PL, BL, Hx, Ax i Mx per aixecar o baixar el llapis, girar i moure'l. L'activitat mostrava la importància de donar instruccions completes i sense ambigüitats.

2. Sortida de dades

println("Hola ITB!")
print("Hola ITB!")
print("Què tal?")

3. Entrada i variables

println("Quina edat tens?")
var edat: Int = readln().toInt()
println("Tens $edat anys")

4. Condicionals

var vullFormatge: Boolean = true
print("Fent un entrepà de llom")

if (vullFormatge) {
    println("...amb formatge!")
}
